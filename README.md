# dnd by ZxcPap14

ASCII-рогалик с ИИ-мастером: мир придумывает модель, кубики кидает движок.

Янтарный ретро-терминал, туман войны, честные d20, permadeath, ДМ-тролль.

**Играть:** https://zxcpap14.github.io/dnd-by-zxcpap14/ — ставится нечего, один файл в браузере.

## Что умеет

- **Только свободный текст** — никаких кнопок: «иду на север», «пробую подкупить стражу»
- **Мир задаёшь ты** — название и описание; классы, злодей и реалии рождаются из этих слов, без жанровых шаблонов
- **Три главы** — завязка, сгущение, финал: ИИ знает, что от него ждут на этой стадии истории
- **ИИ предлагает — движок решает**: модель возвращает JSON с намерениями, код валидирует и применяет, все броски — seeded RNG
- **Способности придумывает игрок**, ИИ интерпретирует, движок считает
- **Память мастера** — недавние события, важные факты (смерти, закрытые задачи) и репутация фракций не выпадают из контекста
- **Реактивный мир** — репутация у фракций меняет цены у торговца и отношение к партии
- **Забег дня** — галочка на старте: карта и этажи одни и те же у всех, кто играет сегодня
- **Забег переживает закрытую вкладку** — автосейв после каждого хода, на старте «ПРОДОЛЖИТЬ»; в коопе хост возвращается в ту же комнату с тем же кодом
- **Кооп 2–4** — хост создаёт комнату и отправляет другу ссылку `…?join=КОД`: друг открывает её и попадает в лобби сам. Классы и мир хоста подтягиваются к нему
- **Обрыв связи не убивает героя** — 3 минуты на возврат, свой слот и инвентарь на месте
- **Торговец между этажами** — зелья, клинки, броня; цены растут с глубиной и зависят от репутации
- **Чат партии не тратит ход** — «кричу: прикрой меня» работает в любой момент
- **Permadeath + зал славы** — число забегов, лучший этаж, победы, эпитафии
- **Справка в игре** — кнопка «? СПРАВКА»: что можно писать и как это разбирает парсер
- **Отчёт о связи** — кнопка в лобби копирует версию, режим, канал, время входа и последние ошибки страницы
- **20 готовых ASCII-аватарок** на выбор + портрет из ника, если ничего не выбрано
- **4 темы терминала** (янтарь / фосфор / лёд / кровь) + секретная за 10 смертей, CRT-эффекты, тряска, d20, глитч при смерти
- Любой OpenAI-совместимый провайдер (OpenAI, DeepSeek, OpenRouter, Ollama); без ключа играется на офлайн-заглушке

## Кооп

Ход по очереди, ИИ и кубики считает хост («рефери один»), у каждого свой туман войны.

Три канала, интерфейс для остального кода один — `host.js` и `client.js` не знают, откуда пришли байты:

1. **Trystero** — P2P через публичные Nostr-релеи, работает из РФ без VPN.
2. **Свой релей** — WebSocket через Cloudflare Workers. Основной путь для разных сетей: без TURN P2P почти не пробивается.
3. **PeerJS** — последний фолбэк, если релеи недоступны.

Клиент запускает Trystero и релей **одновременно** и берёт первый ответивший канал (вход в лобби ~0,6 с вместо 9 с), проигравший закрывается; PeerJS пробуется только если оба упали.

### Релей

Адрес по умолчанию — `DEFAULT_RELAY_URL` в `src/net/relay.js` (`https://dnd-relay.deniskaz-80.workers.dev`), поэтому игрокам ничего настраивать не нужно. Свой релей:

```bash
npx wrangler deploy          # wrangler.toml готов, получится https://dnd-relay.<аккаунт>.workers.dev
```

Затем впиши адрес в `DEFAULT_RELAY_URL` и пересобери (`npm run build`) либо укажи в «СЕТЬ → Релей» в настройках. Правила комнаты живут в `src/net/relayroom.js` и одинаково работают в Workers (`server/relay-worker.mjs`) и в Node (`server/relay-server.mjs`), поэтому тесты проверяют ровно ту логику, что крутится в бою.

Локальная проверка без Cloudflare:

```bash
npm run relay                # ws://127.0.0.1:9001
```

### TURN и строгий NAT

Бесплатных публичных TURN больше нет, а без него соединение между двумя разными сетями за CGNAT не поднимается — тогда весь трафик идёт через релей, и это нормально. Если хочется P2P, впиши свой TURN в «СЕТЬ»: формат `turn:host:port|логин|пароль` (несколько адресов через запятую) или JSON `{"urls":[...],"username":"...","credential":"..."}`.

### Если связь оборвалась

- Клиент показывает «⚡ СВЯЗЬ ПОТЕРЯНА» и переподключается каждые 3 секунды — код и имя уже известны.
- Хост ждёт 3 минуты и не убивает героя; вернулся — HP и инвентарь на месте.
- Хост перезагрузил вкладку — «ПРОДОЛЖИТЬ» поднимет комнату с тем же кодом, клиенты вернутся сами.
- Не вернулся за 3 минуты — герой выбывает с эпитафией.

Технические детали: heartbeat каждые 8 с (24 с тишины = обрыв), вернувшийся по тому же имени забирает свой слот вместо «игра уже началась», мёртвый или выбывший герой не блокирует очередь хода.

## Запуск локально

```bash
npm run build     # dist/index.html — один файл без зависимостей
npm run serve     # http://localhost:8080
```

`build.mjs` склеивает модули по списку `ORDER` в один `<script>` и падает, если в бандле оказались два одинаковых имени.

## Разработка

```bash
npm test          # 283 теста движка, кооп-протокола и ИИ-слоя (node --test)
npm run lint      # eslint 10, плоский конфиг
npm run check     # lint + тесты + сборка — то же гоняет CI на каждый пуш
```

CI (`.github/workflows/test.yml`): установка, линтер, тесты, сборка, проверка синтаксиса бандла и стресс-прогон 25 сидов × 200 команд.

Структура:

```
src/
  engine/   — чистая логика: rng, map, player, combat, monsters, merchant,
              story (главы, память, репутация), world (классы и злодей из слов),
              views (снапшоты), game, save
  ai/       — OpenAI-совместимый клиент, промпт ДМа, офлайн-заглушка
  net/      — протокол, сессии хост/клиент, транспорты Trystero / релей / PeerJS,
              правила комнаты для Workers и Node
  ui/       — терминал, портреты, аватарки, темы, звук, localStorage-хелперы
  test/     — node:test
server/     — relay-worker.mjs (Cloudflare) и relay-server.mjs (локально)
build.mjs   — сборка dist/index.html + docs/index.html (GitHub Pages)
```

## Дизайн-принцип

**«ИИ предлагает — код решает».** Модель не меняет состояние напрямую: она возвращает JSON с намерениями (урон, лут, задача, репутация), а движок валидирует границы и применяет. Все броски — детерминированный seeded RNG, поэтому permadeath настоящий, а забег дня у всех одинаковый.
