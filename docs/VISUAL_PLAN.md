# Визуальная спецификация v1.0 (по опроснику из 32 вопросов)

## Базовая тема
- **Несколько тем** с переключателем: Янтарь (по умолчанию) / Зелёный фосфор / Холодный голубой / Кроваво-красный
- **Фон:** зерно + виньетка (усилить текущую), фон чуть глубже чёрного
- **Шрифт:** пиксельный с Google Fonts (Press Start 2P — есть кириллица), фолбэк на Consolas
- **Яркость:** ярче текущей — текст горит, glow усилен

## Карта
- **Наборы символов переключаемые:** Классика (`# . @ >`) / Псевдографика (`═ ║ ╔`) / Блочные тени (`▓ ·`)
- **Стены:** тусклые, отступают на задний план
- **Герой:** глиф на карте + **ASCII-аватар, детерминированно генерируемый из хэша ника** (5–6 строк, одинаковый для одного ника на всех устройствах). Показ в лобби, статусах
- **Туман войны:** появляется мгновенно

## Хроника
- **Расширенная палитра:** магия — фиолетовый, речь NPC — белый, системное — серый, опасность — мигающий красный, бой — красный, лут — зелёный, кубики — голубой
- **Без разделителей**, сплошной поток
- **Печатная машинка** по буквам (остаётся)
- **Текст крупнее:** ~15px

## CRT-эффекты
- Скан-линии тонкие (остаются)
- Glow лёгкий, но заметнее за счёт яркой темы
- **Мерцание — переключаемое** в настройках (выкл по умолчанию)
- **CRT-включение при загрузке:** полоска → развёртка → интерфейс (1–2 сек)

## Динамика боя
- **Тряска экрана при получении урона**
- **Красная вспышка по краям при уроне**
- **Бросок d20: ASCII-кубик** рисуется и «катится» по экрану к результату (звук дроби уже есть)
- **Смерть: глитч-распад** — текст «умирает» посимвольно → глитч → чёрный → экран смерти

## Экраны
- **ASCII-логотип** dnd by ZxcPap14 на стартовом экране
- **Вступление мира: кинематографичный скролл** (текст ползёт снизу вверх, как в Star Wars), кнопка «Пропустить»
- **Экран смерти:** рамка + эпитафия + анимация появления после глитча
- **Favicon:** пиксельная свеча 🕯️

## Интерфейс
- **HP:** блоки `████░░` (остаются)
- **Статы:** панель под картой (остаётся)
- **Курсор ввода:** мигающий блок █
- **Партия в коопе:** в панели статусов (остаётся)

## Звук
- **Слайдер громкости + кнопка mute** в настройках
- **Звуковой сигнал твоего хода** в коопе

## Пасхалки
- **Матричный дождь** в фоне стартового экрана
- Секретная команда **«кофе»** — ДМ наливает ASCII-чашку кофе
- Скрытая тема **«терминатор»** открывается после 10 смертей в зале славы
