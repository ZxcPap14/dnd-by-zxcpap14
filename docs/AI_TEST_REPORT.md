# Рапорт: тестирование ИИ-ДМа с DeepSeek (deepseek-flash)

**Дата:** 2026-10-28 · **Стенд:** движок игры + реальный API · **Ключ:** предоставлен пользователем (в репо не хранится)

## Вердикт

**deepseek-flash работает и рекомендуется для игры. Итоговая оценка: 9/10.**

Все проверки пройдены (17/17) после исправления одного реального бага интеграции. Качество ДМа — высокое: характер (тролль + беспощадность) соблюдается, JSON-контракт 100%, лимиты эффектов не нарушаются.

## 2. Найденный и исправленный баг интеграции

**Симптом:** при `max_tokens` ≤ 600 модель тратила значительную часть бюджета на рассуждение → `content` приходил пустым или JSON обрезался посреди строки (`finish_reason: length`). Генерация классов падала в ~50% случаев, один свободный ход из шести терял JSON.

**Исправления (в игре):**
1. `max_tokens` подняты: классы 300→1500, интро 500→2000, свободные ходы 600→2000 — запас на рассуждение
2. `extractJson()` теперь **спасает обрезанный JSON**: закрывает незакрытые строки/скобки и восстанавливает объект (+5 unit-тестов, включая обрыв на ключе и после запятой)

## 5. Рекомендации

1. **Ротация ключа.** Ключ передавался в открытом виде в чате — рекомендуется перевыпустить его в кабинете DeepSeek.
2. В плейсхолдере настроек игры теперь указан `deepseek-flash` как проверенный вариант.
3. При очень длинных партиях (100+ ходов) можно включить сжатие истории — сейчас контекст пересобирается с нуля каждый ход, так что проблемы нет.
4. Оффлайн-заглушка остаётся рабочим фолбэком: при таймауте/ошибке API игра не ломается.
